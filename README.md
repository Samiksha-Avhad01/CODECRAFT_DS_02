# CODECRAFT_DS_02

## Task 02 - Exploratory Data Analysis

### Objective
Perform data cleaning and exploratory data analysis on the Titanic dataset to explore relationships and identify patterns and trends.

### Dataset
Titanic Dataset

### Work Performed
- Loaded the Titanic dataset.
- Checked the dataset structure and dimensions.
- Identified missing values.
- Handled missing values in Age and Embarked.
- Removed the Cabin column due to a large number of missing values.
- Checked and removed duplicate records.
- Performed exploratory data analysis.
- Analyzed survival based on gender and passenger class.
- Analyzed age and fare distributions.
- Created visualizations to identify patterns and relationships.
- Created a correlation heatmap.

### Key Analysis
- Survival distribution
- Gender distribution
- Survival by gender
- Survival percentage by gender
- Passenger class distribution
- Survival by passenger class
- Survival percentage by class
- Age distribution
- Age vs Survival
- Fare distribution
- Fare vs Survival
- Correlation analysis
